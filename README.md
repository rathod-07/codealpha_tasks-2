 Unemployment Analysis Using C (CodeAlpha_task-2)

**CodeAlpha Data Science Internship – Task 2**

A high-performance C program designed to analyze unemployment rate trends, process CSV records, and evaluate the economic impact of COVID-19 without relying on external libraries.

---

## 📌 Project Overview

This project implements data analysis fundamentals using pure C. It parses raw unemployment datasets from a CSV file, filters valid records, handles tokenization, and computes key statistical metrics to compare employment trends before and during/after the year 2020.

### Objectives
- Analyze raw unemployment rate data efficiently.
- Calculate overall average unemployment rates.
- Identify peak (highest) and lowest unemployment rates.
- Compare unemployment trends before vs. during/after COVID-19.

---

## 🛠️ Technologies Used

* **Programming Language:** C
* **File Handling:** CSV File Processing (`FILE`, `fgets`, `strtok`)
* **Compiler:** GCC
* **IDE:** Visual Studio Code
